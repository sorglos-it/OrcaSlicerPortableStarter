## Switch in 3 steps

1. Download `portable_orcaslicer.exe` from the [Portable Starter release](https://github.com/sorglos-it/portable-starter/releases/latest).
2. Copy it into your OrcaSlicer folder, next to `orca-slicer.exe`.
3. Double-click it. Your `profile` folder stays in use – `OrcaSlicerPortableStarter.exe` is no longer needed.

The old `OrcaSlicerPortableStarter.exe` stays available on the [Releases](../../releases) page of this repository.
